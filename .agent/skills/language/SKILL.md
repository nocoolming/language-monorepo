# Bilingual Communication Skill / 双语沟通技能

## Purpose / 目的

This skill ensures that all AI responses are provided in both Chinese and English, maintaining consistency across all communication types.

本技能确保所有 AI 回复同时以中文和英文提供，在所有沟通类型中保持一致性。

---

## Rules / 规则

### 1. Conversation Responses / 会话回复

All conversational replies from the AI MUST be bilingual:
- Provide the Chinese version first
- Follow with the English version
- Use clear visual separation (horizontal rule `---` or headers)

所有来自 AI 的会话回复必须是双语的：
- 首先提供中文版本
- 然后提供英文版本
- 使用清晰的视觉分隔（水平线 `---` 或标题）

### 2. Plans and Tasks / 计划和任务

All planning documents, task lists, and implementation plans MUST be bilingual:
- Each section should have both Chinese and English headings
- Descriptions and action items should be in both languages
- Use parallel structure for easy reading

所有规划文档、任务列表和实施计划必须是双语的：
- 每个部分应有中英文标题
- 描述和操作项应使用双语
- 使用平行结构便于阅读

### 3. Reports and Summaries / 报告和总结

All reports, summaries, and walkthroughs MUST be bilingual:
- Include both language versions in the same document
- Maintain consistent formatting between languages

所有报告、总结和演练必须是双语的：
- 在同一文档中包含两种语言版本
- 在语言之间保持一致的格式

---

## Format Example / 格式示例

```markdown
## 功能说明 / Feature Description

这是一个示例功能描述。
This is an example feature description.

### 实现步骤 / Implementation Steps

1. 第一步 / Step one
2. 第二步 / Step two
3. 第三步 / Step three
```

---

## Exceptions / 例外情况

The following content does NOT need to be bilingual:
- Code comments (use the project's standard language)
- Variable and function names
- Technical identifiers and paths
- Direct quotes from external sources

以下内容不需要双语：
- 代码注释（使用项目的标准语言）
- 变量和函数名称
- 技术标识符和路径
- 来自外部来源的直接引用
